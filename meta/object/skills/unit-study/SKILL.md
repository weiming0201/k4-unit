# Study — 认识项目

Use the installed Unit rules and this project's applicable guide. Select an understanding request into a bounded task; distinguish the external object's facts from Self's interpretation and unknowns.

Investigate freely within task authority, writing useful observations to work. Compare findings with the task's expectations. Integrate supported understanding into description/guide; route proposed object/tools changes to target pending when closing. Reconstruction-relevant learning for Self goes to meta pending, not directly into meta. No new pending is required when there is no relevant effect.
