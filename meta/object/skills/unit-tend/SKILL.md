# Tend — 维护项目

Use the installed Unit rules, project understanding and selected target requests. Freeze a task with acceptance and write scope. Predict the next bounded action, execute within authority, compare what happened, then choose the next action. Work may include experiments, analysis and non-code deliverables.

Stage local writeback in work. At closure, give each selected request an evidenced disposition; integrate only authorized, checked changes into object/tools. Changed assumptions become understanding pending. Cross-project or self-relevant discoveries are candidates for their respective pending, not immediate changes to their stable content.
