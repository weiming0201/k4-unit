# Revise — 维护自身

Use installed rules and meta understanding. Select target requests, identify affected consumers and freeze the task's acceptance/scope. Preserve the current working version; stage changes in work and test them without prematurely making them operative.

Settle using the task's bound old kernel. Existing observations, external checks and authorization justify adoption; new code cannot certify its own replacement. Check other active tasks before changing structural contracts. After adoption, restart resident services as required and send understanding pending for what must be observed anew. An adapter installation is this same kind of maintenance, not an alternative authority.
