# Guide

Begin with object/rules.md and the workspace's focus plus manifest project index. Choose only the skill and source material relevant to the selected task. The four Unit skill bodies are defaults; authorized instance maintenance can evolve them without inventing a fifth reserved perspective.

The generic kernel runs on a local POSIX filesystem with Python standard library; MCP stdio additionally needs an isolated MCP SDK. No harness-specific registration is installed. tools/adapter.py accepts an explicit local patch through pending and task settlement; it does not download packages or execute install hooks.

When a harness adapter is supplied, first examine its source, baseline, requested effects and checks. Record actual files, registration, loading and behavior as separate observations. Keep generic guidance; add environment-specific guide pages only as supported. Never place secrets in object, pending, receipts or published configuration; use controlled external references.

Changes to rules, skills, mechanics or configuration belong to meta target work. Understanding of their meaning, dependencies and limits belongs here. The old kernel settles a replacement; interrupted requests name their own frozen recovery entry. A successful check is structural evidence, not an authenticity guarantee or proof of task correctness.
